# Catene di Markov parametriche e POMDP
 
Tesi di laurea triennale, Università degli Studi di Torino (Dip. di Informatica), 2024.
Candidato: Paolo Alberto Bordis, relatore: Jeremy James Sproston.
 
Panoramica di DTMC, MDP, catene di Markov parametriche (pMC) e processi decisionali parzialmente osservabili (POMDP), con un esperimento su una griglia 2D svolto con il model checker [Storm](https://www.stormchecker.org/). Il POMDP viene combinato con un controller a stati finiti (FSC) con `k` nodi di memoria, che genera una pMC di cui si sintetizzano i parametri.
